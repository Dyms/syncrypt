# Examples

There are no standalone example projects yet. What exists:

- A headless sync against the in-memory and filesystem providers is the shape of
  `packages/sdk/test/e2e.s3-encrypted.test.ts` and
  `packages/sdk/test/vault-identity.test.ts`.
- Manual recovery without Syncrypt: [docs/user-guide/manual-recovery.md](../docs/user-guide/manual-recovery.md)
  and its script [recover.mjs](../docs/user-guide/recover.mjs).
